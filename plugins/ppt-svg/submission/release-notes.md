# SVG + PPT 0.1.0

- Adds two independent, interoperable skills: `$svg` for one visual and `$ppt` for a complete presentation.
- Grounds outputs in selected documents and images, supports exact short source quotations, and avoids unsupported content expansion.
- Reuses the SVG engine for all PPT diagram slides and exports editable PowerPoint output.
- Includes hosted/local clients, uploaded source and PPTX-template support, seven deck style categories, and repository-specific engineering references.
- Registers a local MCP server with one tool per diagram format and adds deterministic pie, bar, and line chart support.
