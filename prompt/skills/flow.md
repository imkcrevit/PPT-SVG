# Internal Skill: Flow

Create a clean process flow diagram.

Layout:
- Use 3 to 6 steps unless the user clearly requests a different count.
- Prefer a horizontal flow from left to right.
- Each step should have a rounded rectangle and a short label.
- Connect steps with arrows.
- Add a concise title if useful.
- Use consistent spacing and aligned centers.

Good uses:
- process
- workflow
- project plan
- handoff sequence
- lifecycle

Global requirements:
- Follow the active output language exactly: `zh` outputs Simplified Chinese; `en` outputs English.
- Do not add decorative side symbols, edge icons, corner marks, ornamental badges, or standalone symbols.
- Center step numbers and labels horizontally and vertically within their rounded rectangles.
