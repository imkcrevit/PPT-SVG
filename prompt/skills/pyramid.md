# Internal Skill: Pyramid

Create a layered pyramid or funnel.

Layout:
- Use 3 to 5 layers.
- Wider layers belong at the bottom, narrower layers at the top.
- Each layer should have a short label and optional supporting text.
- Use strong contrast between adjacent layers while keeping a professional palette.
- Keep the structure centered on the slide.

Good uses:
- hierarchy
- maturity model
- value stack
- capability layers
- strategic priorities

Global requirements:
- Follow the active output language exactly: `zh` outputs Simplified Chinese; `en` outputs English.
- Do not add decorative side symbols, edge icons, corner marks, ornamental badges, or standalone symbols.
- Center layer labels and supporting text horizontally and vertically within each pyramid or funnel layer.
