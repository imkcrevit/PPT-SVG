# Internal Skill: Architecture

Create a layered architecture diagram.

Layout:
- Use 3 to 5 horizontal layers or zones.
- Group related components inside each layer.
- Use connectors only when relationships are important.
- Keep component labels short.
- Make boundaries, layers, and dependencies easy to distinguish.

Good uses:
- software architecture
- system design
- data platform
- service layers
- integration overview

Global requirements:
- Follow the active output language exactly: `zh` outputs Simplified Chinese; `en` outputs English.
- Do not add decorative side symbols, edge icons, corner marks, ornamental badges, or standalone symbols.
- Center component labels horizontally and vertically within their background shapes or zones.
