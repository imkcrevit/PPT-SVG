# 技能:甘特图(语义)

生成排期 / 甘特图时必须输出语义 Gantt，不要退化成普通流程图、矩阵或架构图。

## 结构

- `type` 必须是 `gantt`。
- 每个顶层节点代表一个任务，`parent` 为 `null`。
- 每个任务必须尽量给出 `start` 与 `end`，使用数字，如周序号、天序号、月序号。
- 如果用户给了基准范围，例如 `第1到第10周`，所有任务的 `start/end` 都按这个基准填写。
- 如果用户给了 `第1-2周`、`第2到5周`、`week 2-5`，解析为 `start: 1, end: 2` 或对应数字。
- `edges` 只用于明确依赖关系，不要用边代替时间条。

## 条内文字规则

- 甘特条内部优先表达时间段，而不是任务说明。
- 不要把长说明塞进条内部。长说明可放在 `detail`，但布局引擎会优先不展示长说明，以避免 `...`。
- 如果时间段文字在短条内也放不下，条内可以没有任何文字；不要强行生成省略号。
- 任务名称放在左侧任务列，由 `label` 表达。

## 输出规则

- 保持任务先后顺序。
- 语言随环境。
- 不输出坐标、尺寸、颜色或形状。
