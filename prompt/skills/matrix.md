# Internal Skill: Matrix

Create a presentation-ready matrix.

Layout:
- Prefer a 2x2 matrix unless the user asks for another grid.
- Use clear row/column headers or quadrant labels.
- Keep each cell label concise.
- Include light dividers and balanced padding.
- Use colors sparingly to separate quadrants.

Good uses:
- prioritization
- positioning
- segmentation
- risk/value analysis
- effort/impact analysis
